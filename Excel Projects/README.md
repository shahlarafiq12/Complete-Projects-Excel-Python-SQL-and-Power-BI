
# Excel Analysis Projects – Tasks 19, 20 & 21

## Overview
This folder contains three Excel-based data analysis projects completed.

## Task 19: Student Performance Analysis
- Created a dataset containing fictional student records.
- Calculated student percentages using Excel formulas.
- Analyzed average, highest, and lowest marks.
- Applied table formatting and conditional formatting.
- Created a student performance chart.

## Task 20: Sales Performance Analysis
- Organized sales records in Excel.
- Cleaned missing and inconsistent values.
- Calculated total revenue and category-wise sales.
- Used SUMIF, SUMIFS, and COUNTIF formulas.
- Created PivotTables and sales charts.

## Task 21: Business Sales Intelligence – Excel Dashboard
- Organized sales data into structured Excel tables.
- Identified missing values and duplicates.
- Created revenue, profit, and profit margin calculations.
- Used advanced formulas and PivotTables.
- Created KPI summaries and an initial dashboard with charts and slicers.

## Tools Used
- Microsoft Excel
- Excel Formulas
- PivotTables
- Conditional Formatting
- Charts and Dashboards
