# Retail Sales Database & Analysis

## Project Overview
This project focuses on building a Retail Sales Database using MySQL and performing data analysis using SQL and Python.

## Technologies Used
- MySQL
- MySQL Workbench
- Python
- MySQL Connector

## Database Structure
The database name is retail_sale.

It contains three tables:
1. Customers
2. Products
3. Orders

## Database Operations
- Database and table creation
- Primary and Foreign Keys
- Sample data insertion
- Data retrieval and filtering
- INNER JOIN queries
- Sales analysis using SUM, AVG and COUNT
- Monthly sales analysis

## Python Integration
Python is connected to MySQL using `mysql-connector-python` to retrieve customer records.

## Project Files
- retail_sales.sql
- python_connection.py
- README.md

## How to Run
1. Open MySQL Workbench.
2. Execute the SQL script.
3. Install the Python connector:
   pip install mysql-connector-python
4. Update MySQL credentials in python_connection.py.
5. Run:
   python python_connection.py
