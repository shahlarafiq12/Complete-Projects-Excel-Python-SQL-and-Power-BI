
End-to-End Business Analytics Project

## Objective
Establish a business analytics project using SQL, Python, Pandas, and Power BI.

## Dataset
Sample Superstore Sales Dataset (1,000 records).

## Business Problem
Analyze sales and profit performance across products, categories, and regions to identify business improvement opportunities.

## Tools Used
- MySQL
- Python
- Pandas
- Power BI
- SQL

## Tasks Performed
1. Selected a business dataset containing 1,000 records.
2. Defined the business problem.
3. Created a relational database in MySQL.
4. Designed customers, products, orders, and order details tables.
5. Imported dataset records into MySQL.
6. Created SQL queries and JOIN operations.
7. Connected Python with MySQL.
8. Used Pandas for data inspection and analysis.
9. Created an initial Power BI dashboard.

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Category-wise Sales
- Region-wise Sales
- Profit by Category
- Top 10 Products by Sales

## Deliverables
- Dataset (CSV)
- SQL source files
- Python scripts
- Power BI report (.pbix)
- Dashboard screenshots
